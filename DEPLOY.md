## Deploy to Vercel

```bash
cd /root/.openclaw/workspace/mission-control
vercel --prod
```

Or via dashboard:
1. Create repo: https://github.com/new → Name: `mission-control`
2. Push code:
   ```bash
   git remote add origin git@github.com:YBOT8AI/mission-control.git
   git push -u origin main
   ```
3. Deploy: https://vercel.com/new → Import `YBOT8AI/mission-control`

**Live URL will be:** `https://mission-control-xxx.vercel.app`
